Cinderkirk
==========

A bell foundry over a burning pit. Fight your way down.

To play, run ./cinderkirk in this folder. To add it to your applications
menu, run ./install-desktop-entry once.

You need a graphics driver with Vulkan 1.2 (any recent Mesa or NVIDIA driver)
and a Linux from 2024 or later (glibc 2.39). The engine's own libraries are in
lib/. Settings, saves and screenshots go in ~/.local/share/cinderkirk.

A controller works for everything; so do the keyboard and mouse.

The game is also in the Snap Store: snap install cinderkirk
